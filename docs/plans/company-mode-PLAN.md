# תוכנית: מצב חברה ב-PassIT (מנהל + שליח)

סטטוס: טיוטה לאישור. נכתב 2026-11-17.
קלט: הצעה `docs/plans/company-mode-PROPOSAL.md`, ספייק `docs/spikes/company-mode.md` (73 מתוך 73 בדיקות מסד נתונים, 7 מתוך 7 תור אופליין), עיצוב מאושר: https://claude.ai/artifact/52sEFdjBbapWT3x64i5xu6
הבדיקה החיה בשני מכשירים לא נעשתה (החלטת בוס: ישר לתוכנית). היא נעשית בסוף פרוסה 4, לפני שבונים את הלוח המלא.

## 1. מצב קיים
- אפליקציה לשליח יחיד: React + Vite, PWA על Vercel, הכול ב-IndexedDB, סידור דרך `/api/optimize` (Google Routes, עד 25 עצירות, קטנוע, "בול בזמן").
- רכיבים שנשתמש בהם שוב כמו שהם: `AddStops` (הקלדה והקראה), `FixList`, `StartPoint`, `DueTime`, `services/geocode`, `services/optimize`, `services/speech`, `services/navigation`, הפרסר.
- Supabase: פרויקט "PassIT" (פרנקפורט) קיים, והסכמה של הספייק כבר רצה עליו.

## 2. החלטות טכניות
| נושא | בחירה | למה |
|---|---|---|
| מבנה | **אפליקציה אחת, שלושה מצבים לפי כתובת**: `/` שליח יחיד (כמו היום), `/admin` מנהל, `/c` שליח של חברה | כתובת אחת לפרסום, אותם רכיבים. משתמש יחיד לא רואה שום שינוי |
| גודל טעינה | `/admin` ו-`/c` נטענים בנפרד (lazy import). supabase-js (כ-200KB) נטען רק בהם | המצב היחיד לא נהיה כבד יותר |
| מסד נתונים | Supabase. הסכמה עוברת מ-`spikes/` ל-`supabase/migrations/0001_company.sql`, ואחריה קבצים ממוספרים לכל שינוי | מקור אמת אחד, ואפשר לראות היסטוריה |

| התחברות שליח | **קישור הזמנה + כניסה אנונימית של Supabase**: השליח פותח את הקישור, מקבל זהות קבועה בטלפון, והקישור משייך אותה לחברה | בלי סיסמה, בלי SMS, בלי עלות. אם השליח מוחק את נתוני הדפדפן, המנהל שולח קישור חדש |
| בניית מסלול אצל המנהל | טיוטה נבנית על המחשב כמו היום (`Plan` ב-IndexedDB, מפתח לפי שליח ויום). "שלח לשליח" כותב את כל המסלול לשרת בפעולה אחת (`send_route`) | ההקלדה, האימות מול Google והתיקונים עובדים בדיוק כמו היום, בלי עשרות כתיבות לשרת באמצע |

| זמן אמת | Supabase Realtime על `stops` ו-`routes` | נבדק בספייק ברמת ההרשאות, לא במהירות (ראו פרוסה 4) |

| מפה | Google Maps JS הקיים (`MapView`) בעיצוב כהה (styles) | אותו מפתח, אותו חיוב |
| עיצוב | ערכת עיצוב מההדמיה: רקע `#0A0E17`, ליים `#C8F560` לכל מה שחי, ירוק נמסר, ענבר הדבקה, ורוד-אדום נכשל, Rubik לכותרות ו-Heebo לטקסט. קובץ `src/company/theme.css` | העיצוב שאושר. המצב היחיד נשאר בעיצוב הנוכחי עד החלטה אחרת |
| סגירת חודש | pg_cron ב-Supabase, ב-1 לחודש ב-08:00 | כבר בסכמה |

## 6. מה צריך ממך (פעם אחת)
1. ב-Supabase: Authentication > Sign In / Providers > להפעיל **Anonymous sign-ins** (בשביל קישורי ההזמנה).
2. ב-Vercel: להוסיף שני משתני סביבה, `VITE_SUPABASE_URL` ו-`VITE_SUPABASE_ANON_KEY`.
3. ב-Supabase: Database > Extensions > להפעיל **pg_cron** (בשביל הסגירה ב-1 לחודש).
