# ספייק: הקראה בעברית לכתובות

קוד זריקה. בודק את ההנחה המסוכנת ביותר בספק (`docs/specs/route-optimizer.md`): האם הקראה רציפה בעברית הופכת לכתובות מדויקות.

## קבצים
| קובץ | מה הוא עושה |
|---|---|
| `parser.js` | מפצל תמלול עברי לכתובות: רחוב, מספר, עיר, ובנוסף דירה, קומה, כניסה וקוד. ממיר מספרים שנאמרו במילים לספרות |
| `cities.js` | רשימת יישובים, שמשמשת לזהות איפה כתובת אחת נגמרת |
| `test-cases.js`, `run-tests.mjs` | בדיקה של הפרסר על 3 תמלולים שכתבתי ביד: `node run-tests.mjs` |
| `index.html` | עמוד הניסוי: מיקרופון, פיצול, אימות מול Google וסימון ידני של מה נכון |

## הדרך הפשוטה
1. לחיצה כפולה על `start.bat`. נפתח חלון שחור, ו-Chrome נפתח על הדף.
2. ממלאים עיר, לוחצים "התחל הקלטה", מקריאים 10 כתובות ולוחצים "עצור הקלטה".
3. לוחצים "פצל לכתובות" ומסמנים "כן" בכל שורה נכונה.
4. לוחצים "הורד תוצאות" ושולחים את הקובץ.

אפשר לדלג על מפתח Google. בלעדיו הדף לא בודק את הכתובות מול המפה, אבל אפשר לבדוק את התמלול ואת הפיצול.

## איך מריצים ידנית, עם אימות מול Google (Windows)
1. **מפתח Google:** ב-Google Cloud Console מפעילים את Maps JavaScript API ואת Geocoding API, ויוצרים API key. מומלץ להגביל אותו ל-`http://localhost:8765/*`.
2. **שרת מקומי:** מתוך התיקייה הזו מריצים `python -m http.server 8765`. אפשר גם `npx http-server -p 8765`.
3. פותחים את `http://localhost:8765` ב-**Chrome**. במחשב ולא בטלפון, כי המיקרופון בדפדפן דורש https או localhost.
4. מדביקים את המפתח, ממלאים עיר ברירת מחדל ולוחצים "התחל הקלטה". מקריאים 10 כתובות אמיתיות ברצף ולוחצים "עצור הקלטה".
5. לוחצים "פצל לכתובות" ואז "אמת מול Google". הדף מסמן אוטומטית כנכונה כל שורה שבה העיר תואמת, נמצא מספר בית והתאמה מלאה. **אתה מתקן את הסימון ידנית** לפי האמת.
6. לוחצים "הורד תוצאות" ושולחים לי את קובץ ה-JSON.
7. חוזרים על זה 3 פעמים, עם 3 רשימות שונות.

## מדד הצלחה
| תוצאה | מה עושים |
|---|---|
| **GO**: לפחות 90% מהכתובות נכונות | ממשיכים לתוכנית ארכיטקטורה |
| **CHANGE**: 70% עד 90% | מוסיפים מסך תיקון, או מחליפים את מנוע התמלול (Google Speech-to-Text, Whisper) |
| **NO-GO**: מתחת ל-70% | הקראה רציפה לא מספיק טובה, והקלט העיקרי הופך להקלדה או צילום |

## איך לקרוא תוצאה
- **השגיאה בתמלול:** כשהתמלול עצמו שגוי, הבעיה במנוע הדיבור.
- **השגיאה בפיצול:** כשהתמלול נכון אבל הכתובות פוצלו לא נכון, הבעיה בפרסר.
- **השגיאה בגוגל:** כשהכתובת פוצלה נכון אבל גוגל החזיר מקום אחר, הבעיה בגיאוקודינג.

תכתוב לי איזה משלושת סוגי השגיאה ראית, כי כל אחד מוביל לתיקון אחר.
